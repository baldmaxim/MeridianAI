# Агент распознавания сканов Meridian

Распознаёт договоры-сканы моделью **chandra-ocr-2** в LM Studio на вашем компьютере.
Документы не уходят ни в одно облако.

## Зачем

Часть договоров приходит сканами, у части PDF испорчен текстовый слой — кириллица записана
латинскими кодами («CTpOHTeJihHO» вместо «СТРОИТЕЛЬНО»). Такой документ немой: поиск по нему
находит 0 фрагментов, и подсказки на переговорах строятся без опоры на пункты договора.

## Как устроено

Сервер Meridian живёт в интернете, LM Studio — на компьютере за NAT. Достучаться с сервера до
него нельзя, а открывать входящий порт на компьютере не стоит. Поэтому направление обращено,
как в агенте MailHub: работа копится на сервере, а агент **сам** ходит за ней по HTTPS.

```
скан загружен → текст битый/пустой → очередь на сервере
                                          │
                  HTTPS, только исходящее ◄┘
                          │
                   агент (ваш компьютер)
                          │  127.0.0.1:1234
                    LM Studio (chandra-ocr-2) → текст постранично → сервер → поиск
```

- **Компьютер выключен — ничего не ломается.** Сканы ждут в очереди со статусом
  «ждёт распознавания» и распознаются, когда машину включат.
- **Страницы сдаются по одной.** После перезагрузки распознавание продолжается с того же места.
- **Модель не запущена — задачи не берутся.** Агент сначала проверяет LM Studio, поэтому
  выключенная модель не сжигает попытки.
- **Частичный текст не принимается.** Документ считается распознанным, только когда сданы все
  страницы: договор с пропавшими пунктами опаснее, чем без текста.

## Установка

1. В LM Studio загрузите `chandra-ocr-2` и запустите сервер (Developer → Start Server).
2. В Meridian: Админка → «Распознавание сканов» → «Подключить компьютер». Скопируйте токен —
   он показывается один раз.
3. Скопируйте папку `ocr-agent` на компьютер и дважды щёлкните `install.cmd`, вставьте токен.

Нужен Python 3.11+ с python.org. Установщик создаёт своё окружение и задание планировщика
«Meridian OCR Agent», которое запускается при входе в систему без окна.

## Файлы в папке установки (`%LOCALAPPDATA%\MeridianOcrAgent`)

| Файл | Зачем |
|---|---|
| `check.cmd` | проверить связь с сервером и LM Studio, очередь не трогает |
| `once.cmd` | один настоящий заход с подробным выводом |
| `logs.cmd` | открыть журнал |
| `meridian-ocr-agent.json` | настройки: токен, адрес LM Studio, модель, DPI, параллельность |

`dpi`: 200 — обычные документы, 300 — мелкий текст и плохие сканы.
`concurrency`: не больше Parallel requests, с которым модель запущена в LM Studio.

## Разработка

```
cd meridian-web/ocr-agent
..\.venv\Scripts\python.exe -m pytest -q
```
